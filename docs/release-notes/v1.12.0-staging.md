## 주요 변경 사항

- **Phase 2 Redis 분산 캐시 도입**: 사용자 정보를 Pod 간 공유 Redis 로 캐싱해 `/me` · 토큰 재발급 · 주문 경로의 DB 조회를 흡수. Phase 1 Caffeine 로컬 캐시 위에 사용자 쪽 병목을 해소.
- **Rate Limiting 적용**: 대기열 진입 API 와 로그인 API 에 IP/유저 기반 Rate Limit 도입으로 부하·악성 트래픽 대응 강화.
- **경기 상태 자동 전환**: 결제 완료로 전석 SOLD 시 `SOLD_OUT`, 취소로 AVAILABLE 좌석 발생 시 `ON_SALE` 로 자동 전환.
- **대기열 오픈 11시 정각 입장 지연 해소**: 진입 판정을 DB `saleStatus` 대신 `openAt` 시간 비교(Lazy) 로 전환해 스케줄러 커밋·캐시 TTL 지연과 무관하게 11:00:00 정시 진입 허용.

## 기획/클라우드팀 참고 사항

### 환경변수
- 기존 `spring.data.redis.*` 설정을 사용. 추가 필요 환경변수 없음.
- Redis 인스턴스에 새로운 key prefix 가 적재됨: `user-by-id::{userId}`, `auth-me::{userId}`

### DB 마이그레이션
- 스키마 변경 없음.

### 부하테스트 재측정 요청
본 배포 후 **3000 VU 부하테스트 재실행 희망**. 이전 베이스라인(04-15) 과 비교해 다음 지표 확인 예정:
- DB 커넥션 peak (이전 ~250 / 270 한도 근접)
- Queue / Seat P95, 503 발생률
- `/me` P99 (이전 400~600ms → 50ms 이하 목표)
