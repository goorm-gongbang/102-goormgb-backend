## 기획/클라우드팀 참고 사항

- **정책 변경**: "경기당 1user 8매" → "**주문당 8매**"로 전환되었습니다. 동일 유저가 여러 주문에 걸쳐 누적 8매를 초과 예매할 수 있으니 기획 의도를 재확인해주세요.
- **에러 코드 변경**: `EXCEEDED_MAX_TICKETS_PER_MATCH` → `EXCEEDED_MAX_TICKETS_PER_ORDER` (프론트 에러 처리 코드 매핑 확인 필요).
- **이메일 버튼 URL**: 프로파일별로 분기되므로 dev/staging/prod 환경변수 배포 시 프론트 도메인이 올바르게 주입되는지 확인이 필요합니다.
- DB 마이그레이션 필요 없음. 환경변수 신규 추가 없음.
