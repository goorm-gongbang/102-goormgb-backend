## 주요 변경 사항

- **READY 슬롯 실시간 회수**: 좌석 홀드 성공 / 결제 완료 시점에 Kafka 이벤트로 Queue 의 READY 슬롯을 즉시 반납하도록 전환. 기존에는 READY TTL(60s) 만료까지 슬롯이 점유돼 뒤에서 폴링하던 대기자가 실시간 승급을 받지 못하던 병목을 제거.
- **Queue 승급 용량 1000 으로 상향**: `promotion-batch-size` 를 100 → 1000 으로 확대해 부하 테스트(1000+ VU) 상황에서의 수용 인원 증가.

## 기획/클라우드팀 참고 사항

### 환경변수 (Queue 서비스 신규 — 기존 Seat / Order-Core 와 동일)

Queue 서비스 배포 시 아래 환경변수가 다른 Kafka 사용 모듈과 동일하게 주입되어야 합니다.

| 변수 | 설명 |
|------|------|
| `KAFKA_BOOTSTRAP_SERVERS` | Kafka 브로커 접속 주소 |
| `KAFKA_PRODUCER_KEY_SERIALIZER` | Producer key 직렬화 클래스 |
| `KAFKA_PRODUCER_VALUE_SERIALIZER` | Producer value 직렬화 클래스 |
| `KAFKA_PRODUCER_ACKS` | Producer acks 정책 |
| `KAFKA_CONSUMER_GROUP_ID` | 미지정 시 `queue-service` 기본 사용 |
| `KAFKA_CONSUMER_KEY_DESERIALIZER` | Consumer key 역직렬화 클래스 |
| `KAFKA_CONSUMER_VALUE_DESERIALIZER` | Consumer value 역직렬화 클래스 |
| `KAFKA_CONSUMER_AUTO_OFFSET_RESET` | 신규 컨슈머 그룹 오프셋 기준(`latest` 권장) |
| `KAFKA_CONSUMER_TRUSTED_PACKAGES` | `com.goormgb.be.kafka.event` 포함 필요 |

### Kafka 토픽

- **신규**: `seat-hold-completed` (Seat → Queue)
- **기존 재사용**: `payment-completed` — 컨슈머 그룹 `queue-service` 로 신규 구독 (Seat 의 기존 구독은 유지)
- DLT 토픽: 오류 시 `seat-hold-completed.DLT`, `payment-completed.DLT` 자동 생성
